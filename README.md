# AI-Powered Study Assistant

## 📌 Overview
This project was developed as part of a hackathon, where I built an **AI-powered study assistant** designed to help students organize their learning more effectively.  
The platform integrates multiple AI-driven tools such as a study planner, chatbot, quiz generator, and flashcards, providing an interactive and personalized learning experience.

## 🚀 Features
- AI-powered **chatbot** for instant Q&A support  
- **Study planner** to organize schedules and track progress  
- **Quiz generator** and **flashcards** for active recall learning  
- Support for **document uploads**, topic summaries, and content-based quizzes  
- Built with advanced AI models for **personalized learning**

## 🛠️ Tech Stack
- **Frontend/Framework:** Streamlit  
- **Backend:** Python  
- **AI/ML:** OpenAI GPT, LangChain, FAISS (for vector database search)  
- **Libraries:** Pandas, Scikit-learn, Numpy, Matplotlib

## 📂 Installation & Setup
1. Clone this repository  
   ```bash
   git clone https://github.com/gpr-27/study-assistant-hub.git
   cd study-assistant-hub
   ```
2. Install dependencies  
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application  
   ```bash
   streamlit run app.py
   ```
