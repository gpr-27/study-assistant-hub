# --- Study Assistant Hub — base dependencies ---

# The heavy retrieval stack (FAISS + local fastembed embeddings + the langchain-community
# loaders/splitters) lives in requirements-rag.txt and is installed ONLY for the full
# container / local deployment. On serverless the app runs in direct-text "lite" mode
# (backend.config.RAG_ENABLED=False), so those packages aren't needed and would blow past
# the function size limit.
#
#   • Serverless (Vercel) / CI:  pip install -r requirements.txt
#   • Full app (Docker / local): pip install -r requirements.txt -r requirements-rag.txt
#
